# Blog app

This is a **modern blogging platform** built with Next.js, featuring user authentication, blog post management, and a clean, intuitive interface.

## Features

- **Create and manage blogs** - Share links to interesting blogs and like them
- **User profiles** - See the blogs added by each user
- **Authentication** - Secure login and registration
- **Reading list** - Save blogs from other users and mark them as read

## Getting Started

To start exploring:

1. [Register](/register) for a new account
2. [Login](/login) to add your own blogs
3. [Create a new blog post](/blogs/new)
4. View [all blogs](/blogs) and [users](/users)
